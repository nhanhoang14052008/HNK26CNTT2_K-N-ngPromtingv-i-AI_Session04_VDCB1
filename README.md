
# 1. Phân tích lỗi
- Lời chào: "Xin chào, rất vui được hỗ trợ bạn."
- Lời dẫn: "Sau đây chúng ta cùng tìm hiểu."
- Lời kết: "Hy vọng câu trả lời hữu ích với bạn."

# 2. Prompt tối ưu

Hãy giải thích ngắn gọn 3 nội dung: Chain-of-Thought, Prompt Chaining và xử lý đứt gãy.

Yêu cầu:
- Trình bày bằng gạch đầu dòng.
- Mỗi nội dung tối đa 2 câu.
- Không viết lời chào, lời dẫn, lời kết.
- Không giải thích dài dòng.
- Chỉ trả về nội dung chính.

# 3. Kết quả phản hồi
- **Chain-of-Thought:** Chia vấn đề thành từng bước logic để AI xử lý.
- **Prompt Chaining:** Chia nhiệm vụ lớn thành nhiều bước nhỏ liên kết với nhau.
- **Xử lý đứt gãy:** Tóm tắt thông tin quan trọng để tiếp tục công việc khi hội thoại bị gián đoạn.

**Kết luận:** Prompt có cấu trúc giúp AI trả lời ngắn gọn, đúng trọng tâm.
